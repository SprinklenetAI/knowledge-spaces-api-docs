# Contributing

Document only the public developer API surface: endpoints that authenticate with the Organization API Key, plus the unauthenticated rate-limit policy.

Do not include real credentials, real bot or organization identifiers, internal or administrative endpoints, source-file references, private hostnames, environment variable names, sensitive identifiers, or implementation details.

Use placeholder values in all examples (`ks_live_your_key_here`, `YOUR_BOT_ID`), and generate a new UUID for every example `session_id`.
